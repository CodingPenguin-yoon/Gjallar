# 문서 안내

**목표는 PRD, 현재 구현은 아키텍처, 다음 작업은 로드맵에서 확인합니다.**

| 문서 | 관리할 내용 |
|---|---|
| [PRD](prd.md) | 제품 가치·사용자·기능 목표 |
| [아키텍처](architecture.md) | 현재 구조·핵심 API/DB 계약·실행과 복구 제약 |
| [로드맵](roadmap.md) | 구현된 범위·다음 일·후속 후보 |
| [개발·운영](development.md) | 설치·실행·테스트·migration·장애 대응 |
| [작업 기록](work/README.md) | 의미 있는 변경의 이유·계획·결과·검증 |

새 세션에서 구현을 시작하거나 이어가려면 [Goal 실행 프롬프트](goal-prompt.md)를 사용합니다. 제품 범위와 진행 상태는 위 현재 문서를 기준으로 확인합니다.

## 관리 규칙

- 같은 사실은 한 문서에서 관리합니다. 도메인·API·DB·ADR·프로필 문서를 별도로 늘리지 않습니다. 코드에 있는 목록보다 코드만 보고 놓치기 쉬운 계약과 제약을 기록합니다.
- 큰 작업은 `work/YYYY-MM-DD-topic.md` 한 파일에 계획을 작성하고, 진행 후 결과·검증·남은 일을 이어 씁니다. 작은 수정은 Git으로 충분합니다.
- 작업이 끝나면 해당 현재 문서와 로드맵을 함께 갱신합니다. 목표·구현·검증·배포는 구분합니다.
- 공동 문서는 한국어, 저장소 README는 영어 기본·한국어 번역입니다. 작업 안전 기준은 [AGENTS.md](../AGENTS.md)를 따릅니다.

과거 ADR·종료 계획·검증 원본과 통합 전 상세 문서는 [원본 보관 안내](archive/README.md)에서 찾습니다. 평소에는 위 문서만 읽고 갱신하면 됩니다.

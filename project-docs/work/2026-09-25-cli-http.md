## 범위·검증·복구 계획

웹 내부망 HTTP 공개와 CLI의 원격 HTTPS 강제 정책 차이를 해소한다. `connect --allow-http`로 해당 연결의 HTTP 사용을 명시적으로 허용하고 설정에 보존한다. 옵션을 생략한 기존 연결은 기존 정책을 유지한다. HTTP는 비밀번호·세션을 암호화하지 않으며 등록 시 stderr로 안내한다. HTTPS 인증서 검증·redirect 금지·origin별 session 격리는 유지한다. 서버·Proxmox 정책, DB, 배포 및 live 접속은 변경하지 않는다.

기존 설정을 읽을 수 있도록 version 1 profile에 선택적 boolean `allow_http`를 추가한다. 누락 시 false로 해석하고 잘못된 타입은 거부한다. 연결 등록·재로딩·API transport의 URL 검증에 동일 정책을 적용한다.

검증: 기본 원격 HTTP 거부, 명시적 허용·설정 재로딩·로그인/조회, 잘못된 URL 및 flag 타입 거부, redirect 차단과 연결별 격리를 회귀 검사한다. 공통 로컬 및 container 검증과 diff 검사를 실행한다.

복구: HTTP 연결의 session을 logout으로 폐기하고 HTTPS/SSH tunnel 연결을 새 별칭으로 등록한다. 구버전 client로 되돌리기 전 새 필드가 있는 profile은 별도 보존 후 제거해야 한다(구버전은 미지원 필드를 거부). 서버 schema 변경은 없다.

## 결과·남은 일

- `connections.py`: 연결별 `allow_http` 저장·구버전 profile 읽기·boolean 검증.
- `cli.py`: `connect --allow-http`와 stderr 비암호화 경고.
- `api.py`: transport 생성 전 동일 origin 정책 재검증. TLS 검증·redirect 금지는 유지.
- `test_http_connections.py`: 원격 IPv4/IPv6/hostname opt-in, URL 제약, 저장·재로딩·로그인/조회/logout, session 분리, 잘못된 설정·redirect 거부를 추가 검증.
- 아키텍처·개발 안내·로드맵·작업 목록을 현재 동작에 맞춰 갱신했다. 기존 frontend 및 다른 work 변경은 보존했다.

검증:

- 최초 sandbox의 `pnpm run test:client`: 285 통과, 기존 bootstrap socket bind 테스트 1개가 권한 제한으로 실패. 제한 밖에서 재실행한 공통 검증에서는 통과했다.
- Node 24 경로의 `pnpm run verify`: Client 286 통과, Backend 1,696 통과·78 skipped, Frontend test/lint/build 통과. Backend dependency deprecation 및 Vite chunk 크기 경고가 있다. 별도 PostgreSQL 통합 검사는 실행하지 않았다.
- `pnpm run verify:container`: Client 286 통과, Backend 1,696 통과·78 skipped, production 이미지 빌드 통과. frontend/runtime build는 Docker 캐시를 사용했으며 로컬 frontend test/lint/build는 실제 실행했다.
- `client/.venv/bin/gjallar connect --help`: 새 옵션 및 비암호화 설명 확인.
- `git diff --check`: 통과.

실제 서버 접속·배포는 이번 범위에 포함하지 않는다. HTTP는 암호화되지 않으며 별도 설치된 client는 업데이트 후 새 옵션을 사용할 수 있다.

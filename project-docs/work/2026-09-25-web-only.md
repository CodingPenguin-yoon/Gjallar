# 웹 중심 제품 범위 전환과 사용자 CLI 제거

- 상태: `IMPLEMENTED`
- 결정: 2026-09-25 사용자가 빠른 완성을 위해 CLI 제거 방향을 선택했다. 직전 제안의 설치·업데이트·기동·복구용 최소 운영 명령 보존을 따른다.

## 범위·위험·복구

VM·템플릿·모니터링·연결 등록 등의 사용자 CLI/TUI, API client, Keychain/SecretService·memory session, 연결 profile과 전용 workflow를 제거한다. 웹 기능과 `/api/v1` 인증·권한·실행·잠금·복구·DB 계약은 변경하지 않는다. 웹 업무에 필요한 테스트는 유지한다.

기존 설치를 관리할 `gjallar bootstrap`, `gjallar service start/status/stop`, `gjallar upgrade`만 남긴다. package/entrypoint와 `client/` 경로는 기존 설치 갱신 호환을 위해 유지하며 새로운 API client는 제공하지 않는다. bootstrap은 CLI 연결 profile을 생성하거나 로그인을 요구하지 않고 웹 주소를 안내한다. 기존 Compose/manifest/volume/암호화 키와 DB 준비·복구 로직은 그대로 보존한다. atomic 파일·잠금 helper만 설치 전용 모듈로 분리한다. HTTP·keyring runtime dependency를 제거하고 원본 pyproject에서 lock을 재생성한다.

구버전 CLI 명령은 새 버전에서 지원하지 않는다. 기존 설치의 profile·OS keyring·검토 파일은 자동 삭제하지 않는다. 기존 CLI session 폐기가 필요하면 웹의 세션 관리에서 처리한다. 실제 서버 배포·Proxmox 실행·운영 DB 변경·외부 파일 삭제는 범위 밖이다. 되돌림은 이전 패키지/소스를 복원하되 현재 변경 전의 로컬 HTTP 수정도 이전 작업 기록과 함께 보존 근거로 삼는다. DB rollback은 필요하지 않다.

## 구현·검증 계획

1. 최소 운영 명령으로 entrypoint를 축소하고 사용자 client 및 테스트를 제거한다. 설치·서비스·upgrade 안전 계약과 외부 웹 cookie 검사는 유지한다.
2. 제거된 명령의 무부작용 거부, bootstrap의 웹 안내·설정 미작성, 안전한 관리자 입력과 service/upgrade 전달을 검증한다.
3. PRD·아키텍처·로드맵·개발 안내·Goal 프롬프트·README를 웹 중심 현재 상태로 갱신한다. 과거 실행/검증 기록은 보존하며 현재 유지 권한으로 해석하지 않는다.
4. `git diff --check`, 공통 로컬 `pnpm run verify`, 기준 `pnpm run verify:container`를 실행한다. 실제 설치/VM 생성은 별도다.

## 진행·결과

- `client/src/gjallar_client/cli.py`: bootstrap/service/upgrade로 축소. 사용자 로그인·API 명령은 부작용 전에 거부하고 웹을 안내한다.
- `storage.py`: 기존 atomic JSON·전용 디렉터리·잠금 helper를 설치 도구로 이동. `bootstrap.py`는 import만 변경하고 설치·Compose·DB 안전 로직은 보존했다.
- API client·workflow·TUI·session/profile 모듈과 전용 테스트 제거. 서버의 외부 웹 cookie/origin 검사는 `test_managed_web.py`로 보존했다. 기존 서버 인증·VM API 테스트는 그대로 유지했다.
- package는 0.2.0이며 외부 runtime dependency가 없다. pyproject 원본에서 uv lock/requirements를 재생성했다. offline cache 부재로 registry metadata를 사용했으며 기존 pytest 고정 버전은 유지했다.
- PRD·아키텍처·개발 안내·로드맵·Goal 프롬프트·README·AGENTS의 제품 범위를 웹 중심으로 갱신했다. 기존 work의 실행 이력은 보존하고 현재 범위 전환 안내를 추가했다. 웹 Proxmox 연결 완료 안내에서 CLI 참조를 제거했다.
- 삭제된 모듈이 wheel에 남지 않도록 기존 generated `client/build`를 `/tmp/gjallar-old-build-x0k31_tj/build`에 보존 후 새로 빌드했다. 이전 dist 및 외부 설치/profile/keyring은 변경하지 않았다.

- `pnpm run verify` (Node 24): 설치 도구 45 통과, Backend 1,694 통과·78 skipped, Frontend test/lint/build 통과. Backend dependency deprecation과 Vite chunk 크기 경고가 있다. 별도 PostgreSQL 통합 검사는 미실행이다.

- `pnpm run verify:container`: 설치 도구 45 통과, Backend 1,694 통과·78 skipped, Frontend test/lint/build와 production 이미지 빌드 통과. 서비스 기동·배포는 하지 않았다.
- `git diff --check`: 통과.

남은 일: 실제 서버에 새 설치 패키지를 적용하거나 웹에서 VM을 생성하지 않았다. 기존 배포에는 예전 CLI가 남아 있을 수 있으며 별도 패키지 갱신이 필요하다. 제품 전체의 실환경 잔여 검증은 로드맵을 따른다.

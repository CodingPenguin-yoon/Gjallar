## 중단과 재개를 위한 기록

큰 마일스톤 완료뿐 아니라 의미 있는 기능·검증 묶음 완료, 중요한 결정·차단 발생, 중단·세션 인계 전에 현재 work를 갱신한다. 갑작스러운 종료 직전 기록은 보장할 수 없으므로 진행 중에도 저장한다. 매 도구 호출의 로그는 복제하지 않는다.

진행 중 work의 `재개 지점`에는 다음을 유지한다.

- 마지막 갱신 시점과 현재 마일스톤·기능 ID
- 완료한 내용과 수정한 주요 파일
- 실행한 검증·결과와 미실행 항목
- 진행 중·결과 미확정 작업, 시크릿 없는 Operation ID와 상태 확인 방법
- 결정 사항·승인된 범위·승인 대기 또는 차단 사유
- 다음에 할 구체적인 행동

M1~M6를 마칠 때는 해당 work에 사용자 결과·검증 근거·제한·남은 일을 요약하고 로드맵 상태와 링크를 갱신한다. 새 work는 이 목록에 연결하되 세션별 인계 문서를 별도로 늘리지 않는다. 구현 검증 완료와 실환경 검증 대기를 구분하며, 필요한 검증이 남은 마일스톤은 전체 완료로 표시하지 않는다.

새 세션은 로드맵과 연결된 work의 재개 지점을 읽고 현재 코드·diff·실행 상태와 대조한 뒤 이어간다. 기록만 믿고 미확정 외부 작업을 재실행하지 않는다. 문서 저장은 커밋·푸시를 의미하지 않는다.

작업 완료 시 아키텍처·개발 안내 등 바뀐 현재 문서와 로드맵을 갱신한다. 커밋·PR이 있으면 연결한다. 시크릿이나 민감한 원문 로그는 기록하지 않는다. [이전 작업 원본](../archive/README.md)은 역사이며 새 구현이나 live 실행의 승인이 아니다.

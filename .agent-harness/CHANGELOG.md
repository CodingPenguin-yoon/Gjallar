# Harness Changelog

## 1.1.0 - 2026-07-23

- 사용자 제품 방향, Specification, ADR, Plan, 코드·테스트 사이의 의사결정 위계를 명문화했다.
- 현재 상태, 과도기 호환성 상태, 최종 목표 상태를 분리하고 제거·대체 대상의 무승인 확장을 금지했다.
- 중요한 승인에 허용 범위와 승인하지 않은 범위를 한 문장으로 재진술하는 절차를 추가했다.
- 긴 작업 재개와 맥락 압축 뒤 최신 결정 상태를 다시 확인하도록 강화했다.
- Project Profile·Specification·Architecture·Plan·ADR 템플릿과 계획·문서 동기화·품질 리뷰 Skill에 방향 이탈 방지 검사를 추가했다.

## 1.0.0 - 2026-07-16

- 기술 중립적인 Core 원칙과 위험 기반 작업 흐름을 정의했다.
- Spring Boot, FastAPI, React preset을 독립적으로 제공했다.
- 신규 프로젝트 설계, 고위험 계획, 문서 동기화, 품질 리뷰, 기존 프로젝트 도입, 아키텍처 개선 Skill을 추가했다.
- 프로젝트 공동 문서와 Git에서 제외되는 개인 문서를 분리했다.
- 모든 변경 문서, 고정 LOC 게이트, 커스텀 검사기, CI/CD, Runbook, `.codex/` 의존성을 제거했다.
